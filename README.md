# A2-3-project-C

# 📊 AI 리뷰 감정 분석 & 비즈니스 인사이트 대시보드

> Amazon 상품 리뷰를 수집하고 AI로 감정·키워드를 분석한 뒤,
> 통계와 시각화를 통해 **고객의 주요 반응과 개선 포인트를 도출하는 CLI 기반 Python 분석 서비스**

---

## 1. 프로젝트 목표

수백~수천 개의 리뷰를 사람이 직접 읽지 않고,

```text
Amazon 리뷰
    ↓
데이터 정제
    ↓
AI 감정 분석
    ↓
통계 분석
    ↓
시각화
    ↓
비즈니스 인사이트
    ↓
리포트 / Export
```

의 흐름으로 자동 분석한다.

### 핵심

단순히 **긍정/부정을 분류하는 것**에서 끝내지 않고,

* 고객이 무엇을 좋아하는지
* 무엇을 불만스러워하는지
* 시간이 지나면서 감정이 어떻게 변하는지
* 별점과 실제 텍스트 감정이 어떤 관계인지
* 어떤 문제를 우선 개선해야 하는지

까지 보여주는 것을 목표로 한다.

# 2. 개발 범위

### 데이터 수집

기존 팀원이 보유한 **Amazon 상품 리뷰 크롤링 프로그램을 최대한 재사용**한다.

크롤링 결과는 CSV/Excel 등으로 전달받아 분석 파이프라인에 연결한다.

> 새로운 크롤러 개발은 이번 프로젝트의 핵심 범위가 아니다.

### 필수 기능

* CSV / Excel 리뷰 Import
* Raw / Clean 데이터 분리
* 중복 리뷰 처리
* SQLite 또는 JSONL 영구 저장
* AI 감정 분석

  * 긍정 / 부정 / 중립
  * confidence score
* AI 키워드 / 요약 / 개선 제안
* 리뷰 조회 및 필터링
* 통계 분석
* matplotlib 시각화
* Markdown/TXT 리포트
* CSV / JSONL / Excel 중 2개 이상 Export
* argparse 기반 CLI
* logging 및 config 관리

# 3. 대시보드 구성

이번 과제에서는 **웹 대시보드를 만들지 않는다.**

정적 PNG 차트와 Markdown/TXT 리포트 형태로 구성한다.

### 핵심 지표

```text
총 리뷰 수
평균 별점
긍정 비율
부정 비율
```

### 필수 차트 3종

**① 감정 분포**

> 긍정 / 중립 / 부정 비율

**② 시간별 감정 추이**

> 날짜 또는 기간별 긍정·부정 변화

**③ 별점별 감정 분포**

> 1~5점과 AI 감정 결과의 관계

### 추가 권장

**④ 부정 키워드 TOP 5**

> 배송 / 포장 / 품질 / 가격 등 주요 불만

### 최종 리포트

```text
핵심 지표
+ 차트
+ TOP N
+ AI 요약
+ 주요 불만/칭찬
+ 개선 제안
```

# 8. 프로젝트 성공 기준

> **"리뷰를 많이 수집했다"가 성공이 아니다.**

최종적으로 다음 질문에 답할 수 있어야 한다.

**고객은 무엇을 좋아하는가?**

→ 긍정 키워드

**고객은 무엇을 불만스러워하는가?**

→ 부정 키워드 TOP N

**문제가 언제 증가했는가?**

→ 시간별 감정 추이

**별점과 실제 감정은 일치하는가?**

→ 별점-감정 분석

**무엇을 개선해야 하는가?**

→ AI 요약 + 데이터 분석 + 개선 제안

### 최종 목표

> **대량의 Amazon 리뷰를 AI와 데이터 분석으로 빠르게 이해하고, 실제 의사결정에 활용할 수 있는 인사이트를 자동으로 제공한다.**
